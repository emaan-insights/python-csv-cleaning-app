# CSV Data Cleaning App

A simple and interactive web application built with Python, Pandas, and Streamlit to clean and prepare CSV datasets.

## Live Demo

Try the application here:
https://python-csv-cleaning-app-zrmzbvjukkqhuvz98rpzpr.streamlit.app/

## Features

- Upload CSV files
- Preview uploaded datasets
- View dataset information (rows and columns)
- Detect missing values
- Remove rows with missing values
- Fill missing values with 0
- Detect and remove duplicate records
- Clean column names
- Select columns to keep
- Reset dataset to its original version
- Download cleaned CSV files

## Technologies Used

- Python
- Pandas
- Streamlit

## Installation

1. Clone this repository:

   `git clone YOUR_REPOSITORY_URL`

2. Install the required libraries:

   `pip install -r requirements.txt`

3. Run the application:

   `python -m streamlit run app.py`

## Project Purpose

This project demonstrates practical data cleaning and preprocessing using Python and an interactive web interface.
